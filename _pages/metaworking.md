### What is meta-working?
Getting highs by doing some work that is not actual work but is "tangential" to the real work. 

### Why do I do this?
I don't know, maybe its a mechanism to avoid doing real hard work that drains energy. Maybe some deep lack of purpose. 

### Examples of meta-work
- blogging: designing and enabling the blog webdsite before even having anything to post
- templating: spending time building a notion, obsidian, github repo template before having the actual work

### Examples that might feel like meta-work but are not
- programming: learning syntax of a programming language before working on a project

### How to avoid meta-working?
I think each person has to realize themselves that they are meta-working and go on from there.
